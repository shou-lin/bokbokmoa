# 복복모아 운세 확인

PRD.md의 "규칙 범위"와 "점수 계산"을 그대로 옮긴 시제품 계산기 `fortune.mjs`를 실행해 결과를 보여준다.

## 실행

처음 한 번은 의존성을 설치한다 (`node_modules`가 없을 때만):

```bash
npm install --prefix .claude/skills/fortune
```

그다음 사용자 인자를 그대로 넘긴다:

```bash
node .claude/skills/fortune/fortune.mjs $ARGUMENTS
```

- 인자가 없으면 오늘(KST) 일반 모드 운세를 보여준다.
- 사용자가 생년월일을 말로 알려주면 인자로 바꿔 넘긴다. 예: "95년 3월 15일 오후 2시 반" → `1995-03-15 14:30`, "음력 9월 29일" → `--lunar`, 윤달이면 `--leap`, 시간을 모르면 `모름`.
- "이번 주"는 `--week`(그 주 월~일, `--date`와 함께 쓰면 그 날짜가 속한 주), "다음 10일"처럼 기간을 물으면 `--days`(최대 31)를, 특정 날짜는 `--date`를 쓴다.

## 결과 전달

- 한국·일본·태국·마야·나(사주·수비학)의 출처별 100점 만점 점수와 평균을 보여주고, 맨 위에 한두 줄로 요약한다 (예: "오늘은 이동에는 좋지만 계약은 조심하는 날"). 판단은 사용자에게 맡기고, 출처끼리 어긋나면 그대로 보여준다.
- 서양 규칙(13일의 금요일, 수성 역행)은 점수가 아니라 "조심 알림"으로만 전한다.
- 엇갈림이 있으면 어떤 규칙끼리 부딪히는지 짚어준다.
- 기간을 조회했으면 출력 끝의 "기간 점수"(출처별 평균)를 함께 보여주고, 분야별로 가장 좋은 날과 피할 날을 골라준다.
- 면책 문구를 빼지 않는다. "확률"·"보장" 같은 표현은 쓰지 않는다.

## 개인 정보

- 생년월일시를 파일·메모리·커밋에 저장하지 않는다. 매번 인자로만 받는다.
- 계산은 모두 로컬에서 하고 네트워크로 보내지 않는다.

## 알려진 한계

- 신호 값은 PRD "결정 사항"의 초기값이다. PRD에서 값을 바꾸면 `fortune.mjs`의 표도 함께 고친다.
- 황도·흑도는 절기 월(월건) 기준 12신으로 판정한다.
- 수성 역행은 2026~2027년만 들어 있다.
- 마야 날 이름의 신호는 전통 길흉표가 아니라 날 이름의 뜻에 따른 해석이다.
- 태국 กาลโยค는 2026-04-16 ~ 2027-04-15 한 해만 들어 있다. 그 밖의 날은 태국 점수를 빼고 평균을 낸다.
- 자시 출생은 정자시(자정에 날이 바뀜) 기준이고, 시각은 KST 그대로 쓴다 (진태양시·서머타임 보정 없음).
